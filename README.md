# Könyvnyilvántartó program

## Leírás
A harmadik példát választottam, tehát egy saját mini könyvnyilvántartó rendszert készítettem.

A program lehetővé teszi:

- új könyvek hozzáadását
- könyvek listázását
- keresést cím alapján
- könyvek törlését
- könyvek kölcsönzési státuszának módosítását
- adatok mentését JSON fájlba

A projekt a Python programozás alapvető elemeit alkalmazza:

- fájlkezelés
- JSON feldolgozás
- függvények
- listák és szótárak
- vezérlési szerkezetek
- hibakezelés

---

## Használt technológiák

- Python 3
- JSON

---
